# 친절한 SQL 튜닝 실습 (Oracle)

## 개요
본 레포지토리는 『친절한 SQL 튜닝』을 기반으로  
**SQL 처리 과정, 옵티마이저, 실행계획, I/O**를  
실습과 실행계획 분석을 통해 단계적으로 정리하기 위한 학습 레포지토리이다.

각 장에서 다루는 개념을 단순 요약에 그치지 않고,  
Oracle Database 기준의 **재현 가능한 SQL 실습**으로 확인하는 것을 목표로 한다.

## 목적
- SQL 처리 과정을 실행계획 관점에서 직접 확인한다
- 통계, 힌트, 접근 경로 변화가 옵티마이저 선택에 미치는 영향을 실습으로 검증한다

## 발표 자료와의 관계
이 레포는 스터디 및 발표에서 다룬 이론 내용을  
실행계획과 SQL 실습으로 검증·보완하기 위한 용도로 사용된다.

발표 자료는 개념과 흐름을 설명하고,  
이 레포는 해당 개념이 **DB 내부에서 어떻게 판단되는지**를  
실습을 통해 확인하는 역할을 담당한다.
